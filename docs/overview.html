2. What one row stores

Each weight row is cut into blocks of 16, 32, or 64 weights. A block stores a code per weight and two 8-bit numbers, lo and step. The decoder computes w = lo + code * step. Each row also has three fp16 constants that scale the 8-bit numbers.

The cost in bits per weight (bpw) is nbits + 16/B + 48/K, where B is the block size and K is the row length. Metadata for the smoothing vector is extra.
